# 🎯 나만의 퀴즈 게임

## 프로젝트 개요

Python 기본 문법과 객체지향(클래스), JSON을 이용한 데이터 저장을 학습하기 위해
터미널에서 동작하는 퀴즈 게임을 직접 구현한 프로젝트입니다.
사용자는 퀴즈를 풀고, 새로운 퀴즈를 추가하고, 등록된 퀴즈 목록과 최고 점수를
확인할 수 있으며, 프로그램을 종료해도 데이터가 유지됩니다.

## 퀴즈 주제 선정 이유

IT 및 비즈니스를 공부하는 학습자로서, 개발 기초 상식과 일반 상식을 함께 복습할 수 있는 퀴즈를 직접 만들어보고 싶어 이 주제를 선정했습니다.

## 실행 방법

\`\`\`bash
python main.py
\`\`\`
실행 후 메뉴에 나오는 번호(1~5)를 입력해 원하는 기능을 선택합니다.

## 기능 목록

- **퀴즈 풀기**: 등록된 모든 퀴즈를 순서대로 풀고 채점 결과와 점수를 확인합니다.
- **퀴즈 추가**: 객관식/주관식 문제를 새로 등록할 수 있습니다.
- **퀴즈 목록**: 현재 등록된 퀴즈의 문제 목록을 확인합니다.
- **점수 확인**: 지금까지의 최고 점수를 확인합니다.

## 파일 구조
```
quiz_game/
├── main.py            # 실행 진입점, 메뉴 루프
├── quiz.py             # Quiz 클래스 (문제 1개의 데이터와 채점 로직)
├── quiz_game.py        # QuizGame 클래스 (풀기/추가/목록/점수 로직)
├── data_manager.py     # state.json 저장/불러오기
├── data/
│   └── state.json       # 퀴즈 데이터와 최고 점수 저장 파일
├── docs/
│   └── screenshots/     # 실행 화면 캡처
├── .gitignore
└── README.md
```

## 데이터 파일 설명 (state.json)

- 경로: `data/state.json`
- 역할: 등록된 퀴즈 목록과 최고 점수를 저장하여, 프로그램을 종료했다가
  다시 실행해도 데이터가 유지되도록 합니다.
- 필드 구조:
  \`\`\`json
  {
  "quizzes": [
  {
  "question": "문제 내용",
  "answer": "정답 (객관식은 번호, 주관식은 문자열)",
  "choices": ["보기1", "보기2", "보기3", "보기4"],
  "type": "multiple 또는 short"
  }
  ],
  "best_score": 100
  }
  \`\`\`
